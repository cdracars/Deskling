# Deskling mascot

`deskling-mascot.png` is the original 1536 × 1024 PNG illustration selected as Deskling's static project mascot. It is presented in the repository README and is not bundled into the application.

This is a single illustration with a background, not an animated sprite sheet, transparent character cutout, or ready-to-load character pack. A separate [first animation preview](../characters/cyber-gremlin/README.md) is available as an opt-in runtime pack.
